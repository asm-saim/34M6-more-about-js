//JavaScript (JS) is a lightweight, interpreted programming language primarily used to make web pages interactive and dynamic.

1. What is JIT (Just-In-Time Compilation)?

JavaScript is often called an interpreted language, but modern JavaScript engines (like Chrome's V8) actually use JIT (Just-In-Time) compilation.

Without JIT

A traditional interpreter executes code line by line.
This is flexible but slower.

With JIT

The engine first interprets the code, notices which parts run frequently, and then compiles those parts into machine code.

Example:

for (let i = 0; i < 1000000; i++) {
    console.log(i);
}

Since this loop runs many times, the engine compiles it into optimized machine code, making it much faster.

Why JIT?
Faster execution
Better performance
Optimization while the program is running.

Quick Interview Answer
JavaScript Engine: A program that executes JavaScript code.
V8: Google's JavaScript engine used in Chrome and Node.js.
Execution Context: A workspace where JavaScript stores variables, functions, and execution information while running code.
Call Stack: A stack that tracks which execution context (function) is currently running, following the Last In, First Out (LIFO) principle.

Remember this flow:

Write JavaScript
        ↓
V8 Engine reads it
        ↓
Creates an Execution Context
        ↓
Uses the Call Stack to manage function calls
        ↓
Executes the program
